# الذِّكْر — أذكار الصباح والمساء والأربعون النووية

تطبيق ويب تقدّمي (PWA) إسلامي بالعربية، مصمَّم لجهاز iPad بشكل أساسي:

- **أذكار الصباح والمساء كاملة** (١٧ ذكرًا للصباح و١٩ للمساء) من حصن المسلم، مع عدّاد لكل ذكر وتقدّم يومي يتصفّر تلقائيًا كل يوم.
- **الأربعون النووية كاملة** (٤٢ حديثًا) بنصوصها المشكَّلة كما في طبعة sunnah.com، مع تخريج مختصر، وشرح موجز لكل حديث مُلَخَّص من الشروح المعتمدة (النووي، ابن دقيق العيد في «مطالب أولي النهى/مقاصد الأربعين»، عبد المحسن العبّاد).
- خط كبير قابل للتكبير والتصغير (زرّا أ+ / أ−)، وضع ليلي/نهاري، واجهة عربية RTL بالكامل، وأزرار كبيرة تناسب كبار السن.
- يعمل **دون إنترنت** بعد أول زيارة (Service Worker + Manifest)، وقابل للتثبيت على الشاشة الرئيسية لـ iPad.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملًا في ملف واحد (HTML + CSS + البيانات + المنطق) |
| `manifest.json` | بيانات تطبيق الويب التقدّمي |
| `sw.js` | Service Worker للتخزين المؤقت والعمل دون اتصال |
| `icons/` | الأيقونات (تُولَّد عبر `icons.ps1`) |
| `parts/` | ملفات المصدر المستخدمة في بناء `index.html` |

## التشغيل محليًا

أي خادم ملفات ثابت يكفي، مثلاً:

```
cd dhikr-app
python -m http.server 8080
```

ثم افتر `http://localhost:8080` — أو ببساطة افتح `index.html` مباشرة في المتصفح (الوضع دون اتصال يتطلب الخدمة عبر http/https).

## التثبيت على iPad

1. افتح رابط التطبيق في **Safari** (يجب أن يكون عبر https أو مضيف محلي).
2. اضغط زر المشاركة ⬆️.
3. اختر **«إضافة إلى الشاشة الرئيسية»** (Add to Home Screen).
4. افتحه من الشاشة الرئيسية — سيعمل بملء الشاشة ودون إنترنت.

## ملاحظة على المصادر

نصوص الأحاديث مأخوذة بنصّها من صفحة «الأربعون النووية» بموقع sunnah.com (نص الإمام النووي مع تخريجه)، والشروح الموجزة تلخيص بشري من شروح معتمدة وقد تُخطئ؛ فالرجوع إلى الكتب الأصلية أسلم.
